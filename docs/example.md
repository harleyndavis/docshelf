# Example Document

Welcome to the Markdown Docs viewer.

## Features

- Renders **Markdown** to HTML
- Supports `code blocks`, tables, and more
- Drop any `.md` file into the `docs/` folder and it appears here

## Code Example

```python
def hello(name: str) -> str:
    return f"Hello, {name}!"
```
